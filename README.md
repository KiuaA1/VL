# VL – V Launcher

Minecraft: Java Edition launcher for Android (fork of MojoLauncher / PojavLauncher).

**By kiua** · Landscape · X-style UI · Dynamic Island

## Get the source

Download the full project from **Releases** → `VL-launcher.zip`, or clone after the full source is pushed.

## Build APK (no PC needed)

1. Open this repo on GitHub (phone is fine)
2. Go to **Actions** → **Build VL APK** → **Run workflow**
3. When finished, download the **VL-debug-apk** artifact
4. Install the APK on your phone

## Features

- X-style black/blue UI, landscape only
- Dynamic Island (progress, mod deps Yes/No, updates)
- Instance cards, favorites, search, reorder, duplicate
- Modrinth / CurseForge store
- Mods & resource packs manager + dependency check + auto-install
- Full mouse + custom cursor import
- Skin (Microsoft / offline / local) + Laby
- Custom colors, fonts, island size
- VL branding & logo

Based on MojoLauncher (LGPL). Keep upstream credits.
